# Support Measures

## Введение

Данный проект содержит пример работы с наборами данных из открытых источников с использованием python и pandas.
Для примера используется информация из открытых данных Минпромторга РФ: набор Меры поддержки ГИСП.

## Старт проекта

Старт проекта - с использованием простого bash скрипта, с помощью которого автоматизируем действия по:  
-- созданию директорий проекта;  
-- созданию виртуального окружения;  
-- установки зависимостей;  
-- созданию файла.

После создания файла сделать первый коммит и инициализацию репозитория.
